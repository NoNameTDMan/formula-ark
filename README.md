# FORMULA / ARK — 数式工房 v1.0 prototype

## 更新方法
既存の `formula-forge-beta/` フォルダの **index.html, core.js, main.js, styles.css の4ファイルだけ** をこのZIP内の同名ファイルに差し替えてください。READMEは説明用であり配置不要です。既存のアイコン・manifest・その他のファイルは変更しません。

## 変更点
- 目的関数・材料制約・電力制約・変数上下限を常時表示
- 係数・資源消費・最低/最大稼働を直接編集
- 変更直後に厳密な有界整数計画を再計算
- 最適稼働回数を粒子数で可視化、生産時にアニメーション
- 初回6ステップの操作ガイド
- 研究、契約、3つ目の生産式の解放、4秒ごとの自動生産
- 新しい保存キー `formula-ark-v1-save` を使用し、旧版の保存データは変更しない
- JSONセーブのエクスポート／インポート

## 数理モデル
max Σ aᵢxᵢ, subject to Σmᵢxᵢ≤M, Σeᵢxᵢ≤E, lᵢ≤xᵢ≤uᵢ, xᵢ∈Z≥0. 有界整数ナップサックを動的計画法で厳密に解きます。画面上で変更する数値はすべて実際のモデル係数です。

## 注意点
- 旧版の進行状況は自動引継ぎしません。保存キーを分離しています。
- これは遊びの核を検証するプロトタイプであり、正式公開前にiPhone実機テスト、アクセシビリティ確認、第三者プレイテストが必要です。
- 現バージョンは係数編集の自由度を優先し、演算子の自由結合は未実装です。
